# Meal Planner & Recipes

Приложение для Mac: рецепты с КБЖУ, база продуктов, запасы дома, список покупок и меню на неделю. Claude Desktop и Claude Code работают с ним через MCP. Список покупок попадает на iPhone через «Напоминания».

План и решения — [plan-meal-planner.md](plan-meal-planner.md). Сейчас готовы этапы 0–6:
- каркас проекта, тёмное окно с разделами, база данных и MCP-сервер с инструментом `get_status`;
- база продуктов: 354 продукта с КБЖУ из USDA FoodData Central и с типичных упаковок, единицы и пересчёты, разбор строк ингредиентов;
- экран «Продукты»: поиск без учёта «ё» и окончаний, фильтры, сортировка по колонкам, подгрузка при прокрутке, правка в инспекторе, объединение дублей;
- рецепты: галерея по категориям, как в Notion, и таблица КБЖУ; страница рецепта с фото, видео (YouTube, Rutube, VK, любой iframe), ингредиентами на нужное число порций и шагами; редактор, где ингредиент вписывается строкой «40 г феты»; категории в боковой панели; корзина на 30 дней;
- Claude: MCP-сервер заводит и правит рецепты, категории и продукты, открытое окно сразу показывает изменения; готовые сценарии — импорт рецепта по ссылке, КБЖУ продуктов, перенос рецептов из Notion; кнопки «… с Claude» в приложении;
- запасы и покупки: что есть дома и сколько, наличие в рецепте («есть», «мало — ещё 20 г», «нет»), недостающее одной кнопкой в покупки, список по отделам магазина с «для: Омлет», купленное — в запасы; фильтр «можно приготовить сейчас»; инструменты Claude для запасов и покупок и сценарий «Что приготовить»;
- меню на неделю: сетка «дни × приёмы пищи», рецепты перетаскиваются из списка сбоку, блюда — между днями (с ⌥ — копией); КБЖУ за день на человека и всего; точка на блюде, на которое не хватит запасов; «Покупки на неделю»; «Приготовлено» со списанием из запасов после подтверждения и отменой; свои приёмы пищи; копирование прошлой недели; сценарий Claude «Меню на неделю»;
- iPhone: список покупок в «Напоминаниях» в обе стороны — отмеченное в магазине становится купленным, добавленное родными попадает в список; «Поделиться» рецептом — карточка-картинка под экран телефона и текст.

Значения КБЖУ с пометкой USDA взяты из USDA FoodData Central, SR Legacy (общественное достояние).

## Что нужно

- macOS 26 и Xcode 26.
- [XcodeGen](https://github.com/yonaskolb/XcodeGen): `brew install xcodegen`.
- Для `make mcp-inspect` — Node.js 22.19 или новее (`npx`).

## Как запустить

```bash
make run
```

Проект Xcode генерируется из `project.yml` и в git не хранится. Остальные команды — в [CLAUDE.md](CLAUDE.md).

## Список покупок на iPhone

Настройки (⌘,) → «Напоминания» → «Синхронизировать список покупок», затем выберите список или «Создать список «Покупки»». Чтобы список был и у семьи, откройте его в «Напоминаниях» и выберите «Поделиться списком»: дать доступ можно только там.

## Подключить к Claude

Сначала установите приложение, чтобы у сервера был постоянный путь:

```bash
make install
```

Дальше — Настройки (⌘,) → Claude → «Добавить в Claude Desktop…» и перезапуск Claude Desktop. Там же — фрагмент конфига для ручного добавления и команда для Claude Code в терминале:

```bash
claude mcp add --scope user meal-planner -- /Applications/MealPlanner.app/Contents/Helpers/meal-planner-mcp
```

В Claude Desktop в меню «+» поля ввода появятся сценарии Meal Planner: импорт рецепта по ссылке, дозаполнение рецепта, КБЖУ продуктов, перенос из Notion.
